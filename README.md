## 👋 About This Project

This is the personal portfolio of **Tulika Joshi**, a first-year **BCA student** from Lucknow who is learning C programming and taking her first steps into web development, with DevOps on the roadmap.

It is her **first portfolio website**, built using only the fundamentals: **HTML for structure** and **CSS for styling**. There are no frameworks and no JavaScript. Just clean, readable code that is easy to learn from and easy to extend.

---

## ✨ Features

- 🎴 **Profile card hero** with a monogram avatar (easy to swap for a real photo)
- 🧭 **Sticky navigation bar** with smooth scrolling between sections
- 📖 **About section** with quick-fact tiles
- 🛠️ **Skills** split into *learning now* and *up next*
- 🗺️ **Learning roadmap** shown as a vertical timeline
- 💼 **Projects** pulled from her real GitHub repositories
- 🎯 **Goals** checklist
- 📬 **Contact section** with GitHub and email buttons
- 📱 **Fully responsive**: works on phones, tablets and desktops
- 🎨 **Soft blue theme** controlled by CSS variables, so colors change in one place

## 🚀 Getting Started

No installation or build step needed.

1. **Download or clone** this repository
   ```bash
   git clone https://github.com/tulikajoshi007-a11y/portfolio.git
   ```
2. **Open the folder**
   ```bash
   cd portfolio
   ```
3. **Open `index.html`** in any web browser. That's it! 🎉

---

## 🎨 Customizing

**Change the colors:** edit the variables at the top of `style.css`:

```css
:root {
    --bg: #cce4f1;
    --bg-soft: #c6deed;
    --accent: #3a86b4;
    --accent-dark: #276489;
}
```

**Add a profile photo:** put your photo in the project folder, then in `index.html` replace

```html
<div class="avatar">TJ</div>
```

with

```html
<img src="your-photo.jpg" alt="Tulika Joshi" class="profileimg">
```

**Add a new project:** copy one `<article class="card project">` block in the projects section and edit the title, description and link.

---

## 🌐 Deploy for Free with GitHub Pages

1. Push `index.html` and `style.css` to a GitHub repository
2. Go to **Settings → Pages**
3. Under **Source**, choose the `main` branch and the `/ (root)` folder
4. Save, and your portfolio will be live in a minute or two at
   `https://<your-username>.github.io/<repo-name>/`
